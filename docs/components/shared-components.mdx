All shared components live in `src/components/`. These are reusable primitives, feature-specific components belong in `src/features/`.

## Core controls

### Button

```
src/components/Button/Button.jsx
```

| Prop | Type | Description |
|------|------|-------------|
| `variant` | string | Emphasis: `solid` (default), `soft`, `outline`, `ghost` |
| `tone` | string | Intent: `primary`, `neutral`, `success`, `warning`, `danger`, `info`. Defaults to `primary` for solid and soft, `neutral` for outline and ghost |
| `size` | string | `sm` (24px), `md` (32px, default), `lg` (52px, mobile) |
| `leadingIcon` | string | Iconify icon name |
| `trailingIcon` | string | Iconify icon name |
| `iconOnly` | boolean | Icon-only mode |
| `fullWidth` | boolean | Full container width |
| `disabled` | boolean | Disabled state |
| `loading` | boolean | Spinner over the label (same size and colors), clicks ignored. Automatic while an async `onClick` is pending, so `onClick={save}` with an async `save` needs nothing else |

### Listbox

```
src/components/Listbox/Listbox.jsx
```

The list of options inside every picker: `Select`'s menu, `CheckboxListPopover`,
`RadioListPopover`, `SearchListPopover` and `UserPickerPopover` all render
their rows through it. It owns the rows, the selection mark, sections,
filtering and the keyboard; the picker owns its trigger, search box, header
and footer.

| Prop | Type | Description |
|------|------|-------------|
| `options` | array | `{ value, label, description?, leading?, icon?, disabled?, section?, searchText?, tooltip?, action? }`; `{ type: 'header', label }` is a header |
| `multiple` | boolean | Pick several |
| `value` / `defaultValue` / `onValueChange` | | The pick, or an array of picks |
| `onSelect` | function | Every pick, with the option |
| `indicator` | string | `none` (row tints), `check`, `checkbox`, `radio` |
| `variant` | string | `plain` (default, the pick lists), `menu` (Select's rows) |
| `size` | string | `md` (default), `lg` (avatar and two lines) |
| `query` | string | Filters by label, `searchText` or section |

Keyboard: Up / Down / Home / End move, Enter or Space picks; at either end the
arrow carries on to the surrounding Popover's search box or footer.

## Radix UI primitives

These wrap Radix UI and are named for their role:

- `src/components/Checkbox/Checkbox.jsx`, Checkbox (tri-state)
- `src/components/Dialog/Dialog.jsx`, Dialog and its parts (`DialogContent`, `DialogTitle`, …)
- `src/components/Slider/Slider.jsx`, Slider (one thumb or a range)

They were `ShadcnCheckbox`, `ShadcnDialog` and `ShadcnSlider`; the old paths
still re-export them so open branches build, and lint flags new imports.

## Dates

### Calendar

```
src/components/Calendar/Calendar.jsx
```

One month of days (Figma Fold-Pixel-1.0): the grid only. Every date picker
draws its days with it: `DatePickerPopover` (behind `DatePicker` and
`Input type="date"`), `DateRangePopover` (the filter-chip range picker) and
`DateTimePicker`. Props: `year`, `month` (0-based), `onPick`, `mode`
(`single` | `range`), `selected` or `rangeStart` / `rangeEnd` (plus
`pendingStart` / `previewStart` / `previewEnd` while a range is being picked),
`min` / `max`, `isDayDisabled(iso)` (true, or a reason shown as a tooltip),
`highlighted`. One tab stop; arrows move by day and week, Home / End to the
ends of the week.

Date helpers live in `src/lib/localDate.js`: `parseLocalDate`, `isoFromLocal`,
`todayLocal`, `startOfDay`, `addDays`, `sameDay`, `daysInMonth`, `mdyFromIso`,
`isoFromMdy`. Parse date-only values with `parseLocalDate`, never `new Date()`.

## Disclosure

### Collapsible

```
src/components/Collapsible/Collapsible.jsx
```

A region that folds away, in parts: `Collapsible` (root: `open` /
`defaultOpen` / `onOpenChange`), `CollapsibleTrigger` (the button, with
`aria-expanded` / `aria-controls`) and `CollapsibleContent` (eases its height
and is inert while shut). When the control lives elsewhere, use
`CollapsibleContent` alone with `open`. `Collapse` is its old name.
`CollapsibleSection` is the bordered card built on it.

## Loading

### Skeleton

```
src/components/Skeleton/Skeleton.jsx
```

One shimmering placeholder block (`width`, `height`, `radius`, or a class).
`TableSkeleton`, `SimpleTableSkeleton`, `CardSkeleton` and `TimelineSkeleton`
are layouts built from it; arrange `Skeleton` blocks for anything else, and put
`aria-busy` on the loading region.
