**Population Groups** are named cohorts of members. Build one, then reuse it as an audience filter for campaigns, a saved worklist filter, or a slice for analytics.

Routes: `#/population/population-groups`, `#/population/population-groups-static`, `#/population/population-groups-dynamic`.

## Static vs dynamic

<CardGroup cols={2}>
  <Card title="Static" icon="anchor">
    A frozen list of members you upload or select once. Members never change unless you edit the group. Good for one-time outreach, pilots, or manually curated cohorts.
  </Card>
  <Card title="Dynamic" icon="filter">
    A saved filter definition. The group's membership is re-evaluated every time it's used: so "Members overdue for HbA1c" always reflects today's data.
  </Card>
</CardGroup>

## Walkthrough: build a dynamic group

<Steps>
  <Step title="Open Population Groups">
    In the SubNav → **Population Groups** → **Dynamic**.
  </Step>
  <Step title="Create new">
    Click **+ New Group**. The **Create Drawer** slides in (wide variant for complex filters).
  </Step>
  <Step title="Name and describe">
    Name the group ("HbA1c overdue: Q4 push"), add a description (this appears everywhere the group is used).
  </Step>
  <Step title="Compose the filter">
    Add filter chips: **HEDIS Measure = CDC-HbA1c**, **Gap Type = Open**, **State = TX**, **Assignee = None**. The **Summary panel** on the right shows the live member count as you refine.
  </Step>
  <Step title="Save">
    Click **Save**. The group appears in the Dynamic table with its member count.
  </Step>
</Steps>

## Walkthrough: build a static group by upload

<Steps>
  <Step title="Static → + New Group">
    From the SubNav → **Population Groups → Static → + New Group**.
  </Step>
  <Step title="Upload a CSV or XLSX">
    Drop a file with a Member ID column. The **Processing Host** parses via `xlsxLite` and reports rows imported and rows skipped (with reasons).
  </Step>
  <Step title="Review the diff">
    The summary shows how many members matched cleanly, how many were fuzzy-matched, and how many had no match. Approve or reject fuzzy matches individually.
  </Step>
  <Step title="Save">
    The group is created with the fixed member set.
  </Step>
</Steps>

## Using a group

Population Groups are audiences everywhere:

- **Campaigns**: pick a group as the include audience in the Campaign Builder.
- **Worklist filters**: every worklist's **Population Group** filter chip accepts groups; the table narrows to just those members.
- **Analytics**: filter any dashboard to a group to see program metrics for that cohort.

## Updating groups

- **Dynamic**: edit the filter definition; every consumer sees the new membership on next use.
- **Static**: edit via **Update Population Group** drawer: add/remove members, re-upload a CSV to replace, or merge with another group.
