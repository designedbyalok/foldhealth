The **Campaign** workspace is where you turn a filtered patient list into a coordinated outreach. It has two connected surfaces: a **Campaign Builder** for who/when/how, and an **Email Builder** for the actual message.

## When to use what

<CardGroup cols={2}>
  <Card title="One-Time campaign" icon="paper-plane">
    A single send to a fixed audience, e.g. "Send annual wellness reminder to all Medicare Advantage members over 65 by Friday."
  </Card>
  <Card title="Sequence campaign" icon="list-timeline">
    Multi-step, time-delayed automation, e.g. "Send welcome email on Day 0, SMS reminder on Day 3, follow-up email on Day 7."
  </Card>
</CardGroup>

## Walkthrough: send a one-time email campaign

<Steps>
  <Step title="Open Campaigns">
    Click **Campaign** in the sidebar. You land on the campaign list, tabbed **Active**, **Drafts**, **Ended**.
  </Step>
  <Step title="Create a new campaign">
    Click **+ New Campaign** and pick **One-Time**. The full-screen builder opens with a form pane on the left (500px) and a preview pane on the right.
  </Step>
  <Step title="Define the audience">
    In the **Audience** section, add **Include** filters (Population Group, worklist, saved filter, or ad-hoc filter chips). Add **Exclude** filters if you need to carve people out. The count updates live as you edit.
  </Step>
  <Step title="Pick the send method and schedule">
    Choose **Email** (or SMS if configured). Set **Sender**, **Subject**, and a **Send at** time. Leave send-time blank to save as a draft.
  </Step>
  <Step title="Design the email">
    Click **Edit Email**. The **Email Builder** opens full-screen. See the walkthrough below.
  </Step>
  <Step title="Preview and launch">
    Back on the campaign form, use **Send Test** to email yourself a copy. Verify the preview pane matches. Click **Schedule**, the campaign moves to **Active** with a countdown to send time.
  </Step>
</Steps>

<Note>
Every field in the campaign form auto-saves to Supabase via a 600ms debounce. You can close the browser mid-edit without losing work.
</Note>

## Walkthrough: build an email with the Email Builder

<Steps>
  <Step title="Start from a template or blank">
    The Email Builder opens with a **Header/Footer preset** picker. Pick a saved preset, or start blank.
  </Step>
  <Step title="Drag in blocks">
    From the left **Components** panel, drag blocks into the preview: **Text**, **Heading**, **Image**, **Button**, **Divider**, **Spacer**, **Container**, **Columns**, **Raw HTML**.
  </Step>
  <Step title="Edit inline">
    Click any block to select it. Edit text directly on the canvas. Use the right **Properties** panel to change fonts, colors, padding, alignment, and layout, every value uses design-system tokens.
  </Step>
  <Step title="Preview across devices">
    Toggle **Desktop / Tablet / Mobile** in the top toolbar. The canvas re-flows to the target viewport so you catch mobile-only issues before sending.
  </Step>
  <Step title="Import existing HTML (optional)">
    Click **Code View → Import HTML**, paste a design from another tool, and the builder parses it into editable blocks. Unknown fonts get mapped to Google Fonts via the substitution dialog.
  </Step>
  <Step title="Save and return">
    Click **Save**. The email is stored on the campaign; the builder closes and the preview pane refreshes with the new content.
  </Step>
</Steps>

## Block reference

| Block | Notes |
| --- | --- |
| **Text** | Rich text with inline formatting; supports variables like `{{first_name}}` |
| **Heading** | Presets for Title, Subtitle, Heading, Body, each maps to a token size/weight |
| **Image** | Upload to Supabase Storage or paste a URL; auto-inserts responsive width |
| **Button** | Shape (rounded / pill / square), fill color, hover state, target URL |
| **Divider** | Horizontal rule with configurable color and thickness |
| **Spacer** | Vertical whitespace with pixel control |
| **Container** | Wraps children in a background color + padding; useful for hero blocks |
| **Columns** | 2- or 3-column layouts with independent block content per column |
| **Raw HTML** | Escape hatch, paste custom HTML with variable interpolation |

## Tips

- **Undo/Redo**: `Cmd+Z` / `Shift+Cmd+Z` covers every canvas action; the history stack is unbounded per session.
- **Header/Footer presets**: build once, reuse everywhere. Save from the top-right menu; presets appear as a picker on new emails.
- **Send test**: the top-right **Send Test** popover accepts any email address; useful for showing a draft to a stakeholder without publishing.
- **Auto-save**: the builder writes to the campaign row every few seconds. You'll never lose more than a keystroke or two on a crash.
