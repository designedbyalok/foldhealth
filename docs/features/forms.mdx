**Forms** is a full-featured builder for the questionnaires care teams use daily, HRAs, PHQ-9, GAD-7, patient-intake, SDOH screeners. Forms live in **Settings → Content → Forms**, and every form has three surfaces: **Build**, **Preview**, **Analyze**.

## What's included

<CardGroup cols={2}>
  <Card title="Component catalog" icon="grid">
    Short/long text, single/multi-select, rating, slider, number, date, file upload, matrix, section headers, and more (`componentCatalog.js`).
  </Card>
  <Card title="Conditional logic" icon="code-branch">

## Walkthrough: build a form

<Steps>
  <Step title="Open Forms">
    **Settings → Content → Forms**. The list shows every form; click **+ New Form**.
  </Step>
  <Step title="Start from a template or blank">
    Pick **Blank** or a validated instrument (PHQ-9, GAD-7, HRA, SDOH). Templates come pre-populated with questions and scoring.
  </Step>
  <Step title="Add questions in the Build tab">
    Drag from the **Component Catalog** on the left. Each question has a settings panel on the right, label, help text, required, validation rules.
  </Step>
  <Step title="Wire up logic">
    Switch to the **Logic** tab (`LogicPanel`). Add rules: "If Q3 = No, skip to Q8." Rules are expressed as human-readable IF/THEN and evaluated in order.
  </Step>
  <Step title="Configure scoring">
    Switch to the **Score** tab (`ScorePanel`). Assign per-answer weights, choose scale types, and define thresholds (e.g. PHQ-9: 5 mild, 10 moderate, 15 moderately severe, 20 severe). Watch computed scores in the live sample panel.
  </Step>
  <Step title="Preview">
    Switch to the **Preview** tab: the form renders end-to-end with logic and scoring active, exactly as the patient will see it.
  </Step>
  <Step title="Publish">
    Save and set status to **Active**. The form is now available to worklists, campaigns, and API consumers.
  </Step>
</Steps>

## Walkthrough: send a form to a patient

<Steps>
  <Step title="From a worklist row or patient profile">
    Row ⋯ menu → **Send Form** (or from the profile, Comms tab → **Send Form**).
  </Step>
  <Step title="Pick a form">
    The **FormPicker** opens with the active forms your account can send.
  </Step>
  <Step title="Choose the channel">
    Send via SMS, secure link, or embedded in the patient portal. The link is created via `formLink.js` with a scoped token.
  </Step>
  <Step title="Track responses">
    Open the form → **Analytics** tab (`features/forms/analytics`). Three sub-tabs: **Insight** (score distributions, completion), **Report** (per-question breakdowns), **Responses** (individual submissions).
  </Step>
</Steps>

## Scoring engine

The engine (`scoring/evaluate.js`) supports:

- **Per-answer weights**: different answers to the same question carry different scores.
- **Typed scales**: sum, average, thresholded, or custom expressions.
- **Named sub-scores**: a single form can produce multiple scores (e.g. PHQ-9 total + suicidality flag).
- **Live evaluation**: the ScorePanel evaluates scores as you type in Preview.

Sample validated instruments live in `validatedInstruments.js` with unit tests in `validatedInstruments.test.js`.

## Rendering

Live renders use `FormRenderer.jsx` with:

- **Layout engine** (`layout.js`): sections, pagination, and progress bars.
- **Flow engine** (`flow.js`): evaluates logic rules turn-by-turn.
- **Recall** (`recall.js`): inline variable substitution (`Hello {{first_name}}`).

Every engine has a companion `.test.js` that pins behavior.

## Tips

- **Instruments come with citations.** Validated forms link to the source publication in the settings panel, useful for audit.
- **Logic and scoring are independent.** A hidden question still contributes to score if it was answered before being hidden; configure exclusion in the Score panel if that's not what you want.
- **Analytics is live.** Charts update as new responses land, no batch job.
