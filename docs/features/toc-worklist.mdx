**TOC** is the standalone agent-queue worklist (`#/population/toc`). It is a copy of the TCM Agent Queue: patients who already have an AI agent assigned, with live call status, AI Assessment, and outreach history.

The original care-manager worklist (Worklist + Agent Queue tabs) now lives under **[TCM](/features/tcm-worklist)**.

## Table columns

| Column | Description |
| --- | --- |
| **Members** | Name, gender, age, member ID, preferred language |
| **Program Sub Status** | Enrolled, Engaged, Attempted, New |
| **Admit Class** | Inpatient or Emergency |
| **TOC Acuity** | High / Medium / Low (LACE) |
| **Outreach Status** | Completed, Needs Review, Scheduled, opens Patient Outreach |
| **AI Assessment** | TOC IP/ED Assessment link, opens Patient Assessment |
| **Next Action Due** | Next due date |
| **Outreach** | Last outreach date |
| **Last Outreach By** | Agent or person who last reached the member |
| **AI Tasks** | Open AI task count |
| **Assignee** | Care manager assigned to the row |
| **Nurse/Health Coach**, **Coordinator**, **Social Worker**, **Com. Health Worker** | Care-team roles |
| **Start Date** | Program enrollment date |
| **Last Admission** | Most recent hospital admission |
| **Radar** / **Risk IQ** | Radar score and risk band |
| **Readmission** | Yes / No |
| **Care Plan Status** | Updated, Pending, or No Care Plan |
| **Tags** | Row tags |
| **Actions** | Quick View, place a call, ⋯ menu |

## Empty state

If no agents have been invoked yet, TOC shows **No active agent runs** with a link to the **TCM Worklist**. Invoke an agent from TCM, then return here to monitor the queue.

## KPI summary bar

The bar above the table shows calls placed, connect rate, transfer rate, and average handle time for the current agent runs.

## Walkthrough: monitor agent outreach

<Steps>
  <Step title="Open TOC">
    In Population → Worklists, select **TOC**. The URL is `#/population/toc`.
  </Step>
  <Step title="Scan live status">
    Rows with an assigned agent show On Call, Queued, or Completed. Use the KPI bar to check connect and transfer rates.
  </Step>
  <Step title="Open an assessment">
    Click the **AI Assessment** pill to review the Patient Assessment (PHQ-9 or the form configured in Settings).
  </Step>
  <Step title="Review outreach">
    Click the outreach status to open **Patient Outreach**, the same history as the patient Outreach tab.
  </Step>
</Steps>

## Tips

- **Column prefs are isolated**: hiding or reordering columns on TOC does not change the TCM Agent Queue.
- **Same patient pool as TCM**: invoking an agent from TCM adds the row here (and on the TCM Agent Queue tab).
- **Edit Configuration / Abort** sit in the title bar, same as the TCM queue.
