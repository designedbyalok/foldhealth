The **SNP Worklist** manages members enrolled in **Special Needs Plans**, D-SNP (Dual Eligible), C-SNP (Chronic Condition), and I-SNP (Institutional). SNPs carry strict CMS requirements around annual **HRA** completion, ongoing **ICP** review, and Model of Care goals.

Route: `#/population/snp`.

## Columns

| Column | Description |
| --- | --- |
| **Members** | Name, gender, age, member ID |
| **SNP Type** | D-SNP / C-SNP / I-SNP |
| **HRA Status** | Not started / In progress / Completed + last date |
| **HRA Due** | Deadline for the annual HRA |
| **ICP Status** | Draft / Active / Overdue for review |
| **Care Plan Reviewed** | Last ICDT (Interdisciplinary Care Team) review date |
| **Assignee** | Care manager |
| **Actions** | Open HRA, open ICP, ⋯ menu |

## Walkthrough: chase overdue HRAs

<Steps>
  <Step title="Open SNP">
    Click **SNP** in the SubNav.
  </Step>
  <Step title="Filter to overdue HRAs">
    Set **HRA Status = Not started or In progress** and **HRA Due = Overdue**. The table narrows to CMS non-compliance risk.
  </Step>
  <Step title="Bulk-launch an outreach">
    Select rows and choose **Add to Campaign → SNP HRA Reminder** from the BulkBar. The campaign builder opens with the audience pre-set.
  </Step>
  <Step title="Or complete an HRA in-app">
    Click a row → **Open HRA** from Quick View. The HRA form (rendered by the [Forms](/features/forms) engine) opens; complete it and submit, status flips to Completed and the calendar-clock resets for next year.
  </Step>
</Steps>

## Tips

- **HRA and ICP are separate but linked**, an updated HRA usually triggers an ICP review; both status columns show what's outstanding.
- **CMS auditing.** Every state change in this worklist writes to the audit log; use the ⋯ menu → **Audit** to review a member's compliance trail.
