The **APCM Billing** worklist is CMS **Advanced Primary Care Management** (G0556 / G0557 / G0558) billing. Unlike CCM, APCM is **not time-based**, it's tier-based (Level 1 / 2 / 3 by patient acuity and complexity). This worklist handles the attestation and month-close for those tiers.

Route: `#/population/apcm` (opened from Settings → Billing or from the row menu on CCM).

## Columns

| Column | Description |
| --- | --- |
| **Members** | Name, gender, age, member ID |
| **APCM Level** | 1 / 2 / 3 based on chronic conditions + acuity |
| **Attestation Status** | Missing / Signed / Locked |
| **Consent** | Verbal / Written / Missing |
| **Chronic Conditions** | ICD chip row |
| **PCP** | Attributed primary care provider |
| **Last Interaction** | Most recent qualifying activity |
| **Assignee** | Billing analyst |
| **Actions** | Open Attestation, ⋯ menu |

## Walkthrough: month-close for APCM

<Steps>
  <Step title="Open APCM Billing">
    Route: `#/population/apcm`, or from the CCM row menu → **Switch to APCM**.
  </Step>
  <Step title="Verify eligibility per row">
    Every row must have: valid Consent, an APCM Level assigned, and a qualifying interaction this month. Rows missing any surface a red chip.
  </Step>
  <Step title="Attest for the month">
    Click a row → **Open Attestation**. The **Attestation Modal** walks:
    1. Consent confirmation
    2. Level attestation (auto-computed, reviewer can override with reason)
    3. Signatory form: the billing provider signs off
    4. Result view: locked and ready to bill
  </Step>
  <Step title="Bulk attest">
    For high-volume close, check rows and use BulkBar → **Bulk Attest** (skips rows missing prerequisites).
  </Step>
  <Step title="Export">
    BulkBar → **Export → CSV** produces the batch for your claim system.
  </Step>
</Steps>

## Attestation Modal

A tightly scripted flow (`AttestationModal.jsx`) that enforces four steps in order:

- **Consent Options**: required before proceeding.
- **Level Attestation**: the modal pre-computes based on member data; overrides require a reason.
- **Signatory Form**: the billing provider's name and NPI; auto-stamps a timestamp.
- **Result View**: the locked view. Attestation cannot be edited without unlocking and re-signing.

## Tips

- **APCM ≠ CCM.** They're mutually exclusive for a given month; the row menu on CCM will warn you before flipping a member.
- **Level overrides are audited.** Any override to the auto-computed level writes to the audit log with the reason and user.
